## Installation
1. Available versions can be found here: [Releases](https://github.com/MarvinBeym/MwcModApi/releases)
2. Download the ``.zip`` file for the version your mods need. Note: they are not always upward/downward compatible!
3. Find your **Mods** folder.
   * This can likely be found in your Games folder
4. Extract the ``MwcModApi.dll`` file from the ``.zip`` Archive you downloaded into that Mods folder
5. Start the game
6. Opening the ModLoader settings in the top right corner you should see a new Entry **MwcModApi**
